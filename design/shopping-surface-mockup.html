What this mockup decides & shows

Open question resolved → Recently Bought = de-emphasized and collapsed. It renders as a muted, struck-through summary row under a small disclosure caret, labelled read-only with the "agent clears after ~7 days" note. This answers PRD 02's open design question: it's visible for "did we already get that?" without competing with the active lists, and it visually reinforces that the client never clears it (P0-6 / L3). If it feels too buried in real use at 8 ft, the fallback is de-emphasized-but-always-expanded — one line to change.

Every value is a seed token. Key number type.number (30) in color.accent.shopping (teal.400); combined unchecked count = 3 (D-13); glance line is a derived summary "Grocery 2 · Household 1", not a raw markdown line (L4). Focused view uses bg.raised; checkboxes are sized for touch-without-precise-aim (P0-7).

Plugs in unchanged (P0-8). Shopping simply claims column 1 of the 3-column grid; the header, Assistant Bar band (reserved, tagged Phase 2), Tasks and Mail tiles are untouched shell.

Seed data is mock, shaped like real SHOPPING.md forms — bare item (Eggs), parenthetical note (Milk (2 gallons)), bought ~~text~~ (list, date) — per AGENTS.md (never real family data). Static picture; the checkboxes are illustrative, not the Phase-1 mutation layer.
